Connecting this report to live data

Every value on this page comes from one object, REPORT_DATA, declared at the top of the script block. Replace that object with a response from your own endpoint and the report renders live. Nothing else needs to change.

<script>
  // Replace the static object with a fetch, then call render()
  const res  = await fetch('/api/qe-report?sprint=14&team=all',
                           { headers: { Authorization: 'Bearer ' + token } });
  window.REPORT_DATA = await res.json();
  render();
</script>
